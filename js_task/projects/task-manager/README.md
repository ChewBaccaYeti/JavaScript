# Task Manager - Progressive Learning Project

**Практическое задание с 5 уровнями сложности для освоения всех аспектов
JavaScript.**

## 🚀 Как Начать

1. Откройте `index.html` в браузере
2. Откройте `js/level1/app.js` в редакторе
3. Следуйте TODO комментариям в коде
4. Реализуйте функции одну за другой

## 📚 Файлы

-   **TASK_MANAGER_PROJECT.md** — полное техническое задание со всеми уровнями
-   **js/level1/app.js** — стартовый файл с TODO и подсказками
-   **index.html** — HTML структура со всеми необходимыми элементами
-   **css/style.css** — готовые стили для всех уровней

## 📋 Подсказки

### Как получить значение инпута?

```js
const input = document.querySelector('#taskInput');
const value = input.value;
```

### Как запустить функцию при клике?

```js
const button = document.querySelector('#addBtn');
button.addEventListener('click', () => {
    addTask(someValue);
});
```

### Как создать и добавить элемент в DOM?

```js
const ul = document.querySelector('#taskList');
const li = document.createElement('li');
li.textContent = 'Task text';
li.dataset.id = 123; // или li.setAttribute('data-id', 123)
ul.appendChild(li);
```

### Как сделать цикл по массиву?

```js
// Способ 1: for
for (let i = 0; i < tasks.length; i++) {
    console.log(tasks[i]);
}

// Способ 2: forEach (современнее)
tasks.forEach(task => {
    console.log(task);
});

// Способ 3: map (если нужен новый массив)
const titles = tasks.map(t => t.title);
```
